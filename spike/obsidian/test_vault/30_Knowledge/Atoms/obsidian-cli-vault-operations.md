# The Obsidian CLI exposes vault operations against a running app

The `obsidian` CLI requires a running desktop instance and exposes Daily Note
resolution, note creation, property operations, tags, tasks, search, links,
backlinks, move/rename, and `eval` for arbitrary JS against the app API.
